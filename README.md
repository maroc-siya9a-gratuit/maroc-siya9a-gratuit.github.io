1. **من التيليفون ولا الحاسوب:** دخل لـ [الموقع](https://maroc-siya9a-gratuit.github.io) واختار السلسلة.

## 🇬🇧 English

### What is this?
A free, no-signup website to prepare for the **Moroccan driving licence theory exam** (*Code de la route Maroc*). Every question comes with its picture and a spoken version in Moroccan Darija; the correct answer stays hidden until you have tried, then you reveal it together with an explanation.

**Live site: [maroc-siya9a-gratuit.github.io](https://maroc-siya9a-gratuit.github.io)**

### What's inside

| Section | Count | Contents |
|---|---|---|
| Exam series | 154 series · 5,379 questions | Car (B), Motorcycle (A), Truck (C), Bus (D), Truck with trailer (EC), Mechanics |
| Road signs | 249 signs | Danger, priority, prohibition, obligation, information, temporary, direction, additional — each with picture, meaning and audio |
| Lessons | 32 lessons | Traffic rules, road markings, accidents & first aid, and more |
| Tips | 478 tips | Grouped by topic, each with a picture and an explanation |
| Road cases | 72 cases | Real traffic situations, explained |
| Q&A | 23 | About the licence and the exam |

### How to use it
1. **Online:** open the [site](https://maroc-siya9a-gratuit.github.io) on a phone or a computer and pick a series.
2. **Listen, look, answer**, then tap «بيّن الجواب» (*show the answer*) to check yourself. «بيّن كل الأجوبة» reveals every answer of a series at once, for revision.
3. **Search** from the home page: a sign, a word from any explanation, or a topic. Arabic spelling variants are matched (e.g. `اشارة` finds `إشارة`).
4. **Offline:** **Code → Download ZIP**, unzip, open `index.html` in any browser. Every link is relative, so it works without internet.

### How it is built
Plain static HTML and CSS, a few lines of JavaScript, no framework, no tracking, no cookies, no ads.

```
index.html        home: search, every section, every series
pages/            one page per series, sign group, lesson, tip group; cases; Q&A
media/            images (.webp/.gif) and audio (.m4a), loaded lazily, one page at a time
search.js         search index, downloaded only when you first tap the search box
fonts/ style.css  the TheSans font and the single stylesheet (light + dark mode)
sitemap.xml       for search engines
```

Pages load only their own media, so a phone on mobile data never downloads more than the page it shows.
